Политика конфиденциальности приложения Elviks

1. Сбор данных: Приложение собирает номер телефона пользователя (для авторизации) и токен устройства (для отправки push-уведомлений). Также сохраняются отправленные сообщения и загруженные файлы.

2. Использование данных: Данные используются исключительно для работы мессенджера (связь между пользователями).

3. Хранение: Данные хранятся на защищенных серверах (облачная база данных PostgreSQL).

4. Передача третьим лицам: Мы не передаем данные третьим лицам. Номер телефона передается SMS-сервису только для отправки кода подтверждения.

5. Удаление данных: Пользователь может запросить удаление своего аккаунта и данных, написав на почту: leonidkuklov820@gmail.com.
